# assets/proofs

Rasterized copies of certificates and experience letters, linked from the
site as a muted “View proof” option. Point at a file from `data/links.json`
(`proofs`, `certificate_proofs`, or `role_proofs`), e.g.
`"assets/proofs/name.pdf"`. Public Credly badge pages may be used as
`https://` URLs instead of a file.

Do not commit unredacted originals with a text layer. Rasterize each file
and keep it under 500 KB. Cover only home or personal addresses and
phone/fax numbers, with a light box and the label “Available on request”.
Leave signatures, stamps, QR codes, names, letterhead, and institutional
office addresses visible. A “Email me for redacted details” link next to
each proof points at the site contact address.
