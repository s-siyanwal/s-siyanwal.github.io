# assets/proofs

Redacted, rasterized copies of certificates and experience letters, linked
from the site as a muted “View proof” option. Point at a file from
`data/links.json` (`proofs`, `certificate_proofs`, or `role_proofs`), e.g.
`"assets/proofs/ai-shiksha-2021.pdf"`. Public Credly badge pages may be
used as `https://` URLs instead of a file.

Do not commit unredacted originals. Before adding a file, rasterize it and
black-box signatures, phone and fax numbers, personal emails, home addresses,
salary, ID numbers, and QR codes that encode personal data. Keep institution
names, titles, dates, and the signatory’s printed name and title. Keep each
file under 500 KB.
