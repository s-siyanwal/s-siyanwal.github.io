## How this file works

Each note is one Markdown file in `notes/`. The block between the `---` lines at the top is the front matter:

- `title`: shown on the index and as the page heading
- `date`: `YYYY-MM-DD`, used for sorting (newest first)
- `blurb`: one line shown on the index

The body supports paragraphs, `## headings`, *italics*, **bold**, `inline code`, [links](https://example.com), bullet lists and > quotes.

> Set `draft: true` in the front matter to keep a note out of the build.
